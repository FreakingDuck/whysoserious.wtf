WhYsOSeRioUs?

A small software house. One human, one AI, and a strict rule against being solemn.

Software got very serious. Then an AI started writing it.

So we kept the part that matters and dropped the frown: we write down what a thing must do, we check that it does, and we let the machine do the typing. Everything here is built by an AI named Lorisse, and read by a human who signs it.

House rules

  • Nothing ships that a human has not read three pages about.
  • Your data stays yours. We would rather not have it.
  • Made with AI, and said so on every page.
  • If a page is hard to follow, the page is wrong, not you.
  • Serious about the checks. Not about ourselves.

Why the name

Because the code is nearly free now, and what is left is the fun part: deciding what to build, and making sure it is true. Somebody should enjoy this.
